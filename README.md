# CarePath — Smart IV Pole Robot

제24회 임베디드SW경진대회 자유공모 부문 출품작

환자를 자율 추종하는 스마트 링거대 로봇. 낙상 감지 웨어러블 태그와 연동하여
환자 낙상 시 로봇이 즉시 정지하고 간호사 스테이션에 알람을 전송한다.

## 시스템 구성

| 구성 요소 | 하드웨어 | 역할 |
|---|---|---|
| 로봇 본체 | Raspberry Pi 5, SunFounder PiCar-X | 환자 추종 주행, 회피 기동 |
| 비전 | USB 웹캠 + YOLOv8n | 환자 검출 및 복도 혼잡도 판단 |
| 거리 센서 | YDLiDAR X4 Pro | 전방 및 측면 거리 측정 |
| 환자 태그 | ESP32 DevKit V1, MPU6500, 부저 | 낙상 감지 및 경보 |
| 모니터링 | 노트북 | 간호사 스테이션 알람 수신 |

## 디렉토리 구조

    raspberry_pi/
      main.py            # 메인 제어 루프 (우선순위 상태머신)
      vision_thread.py   # YOLOv8 기반 환자 추적 및 혼잡도 판단
      sensor_thread.py   # LiDAR 거리 측정 및 UDP 낙상 신호 수신
      motor_thread.py    # 애커먼 조향 및 구동 모터 제어
      motor_test.py      # 구동부 단독 검증 스크립트
    esp32/
      patient_tag.ino    # 환자 착용 태그 (낙상 감지 + WiFi 송신)
    laptop/
      fall_monitor.py    # 낙상 알람 수신기

## 동작 원리

### 우선순위 기반 상태 머신

메인 루프는 20Hz로 동작하며 다음 순서로 행동을 결정한다.

0. **코드블루** — 응급 의료진 통행을 위해 우측 벽면으로 회피 기동 후 대기
1. **낙상 감지** — 모든 동력 즉시 차단
2. **복도 혼잡** — 주행 일시 정지
3. **환자 추종** — 대상의 화면상 위치에 따라 조향
4. **대상 상실** — 정지 후 대기

생명 안전이 최우선이며, 하위 순위는 상위 조건이 해제될 때까지 실행되지 않는다.

### 2단계 낙상 판정

단순 충격 임계값 방식은 일상 동작에서 오탐이 잦다. 본 시스템은 다음 시퀀스를 요구한다.

1. 자유낙하 감지 (가속도 0.55g 미만)
2. 0.9초 이내 충격 발생 (가속도 2.6g 초과)

두 조건이 순서대로 충족될 때만 낙상으로 판정한다.
태그는 낙상 확정 시 부저를 울리며 0.3초 간격으로 UDP 신호를 반복 전송하고,
로봇은 마지막 수신 시점으로부터 3초가 지나면 정지 상태를 자동 해제한다.

### 환자 식별

YOLOv8n으로 사람을 검출한 뒤, 각 검출 영역을 HSV 색공간으로 변환하여
지정 색상 픽셀이 차지하는 비율을 계산한다. 비율이 임계값을 넘는 대상 중
화면에서 가장 크게 보이는(가장 가까운) 사람을 추종 목표로 선정한다.

### 코드블루 (응급 통행로 확보)

터미널에서 `c`를 입력하면 코드블루가 발동된다.
로봇은 우측 벽면 방향으로 회피 기동한 뒤 정지하며,
`r` 입력으로 해제할 때까지 그 자리에서 대기한다.

### 스레드 구조

`RobotState` 객체를 `threading.Lock`으로 보호하여 여러 스레드가 공유한다.

- 비전 스레드: 카메라 프레임 처리 및 YOLO 추론
- 센서 스레드: LiDAR 스캔 및 논블로킹 UDP 수신
- 입력 스레드: 터미널을 통한 코드블루 수동 발동
- 메인 스레드: 상태 판단 및 모터 명령

각 스레드는 서로 다른 주기로 동작하며, 공유 상태를 통해서만 데이터를 주고받는다.

## 실행 방법

    # 라즈베리파이
    cd raspberry_pi && python3 main.py

    # 모니터링 PC
    cd laptop && python3 fall_monitor.py

ESP32는 Arduino IDE에서 `patient_tag.ino`를 업로드한다.
업로드 전 코드 상단의 WiFi 정보와 수신 측 IP 주소를 환경에 맞게 수정해야 한다.

## 개발 환경

- Raspberry Pi OS Trixie (Debian 13), Python 3.13
- OpenCV, Ultralytics YOLOv8, PyLidar3, robot-hat
- Arduino IDE 2.3.10 + ESP32 Arduino Core
